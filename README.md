# Ilia Minimal Portfolio

Super minimalist React portfolio and resume page, with six product case studies.

## Run locally

```bash
npm ci
npm run dev
```

## Check and build

```bash
npm test
npm run build
```

## Edit content

Home-page content is in `src/main.jsx`. Product case studies and image paths are in `src/cases.js`. Visual style is in `src/style.css`.

See [CASE_STUDIES.md](CASE_STUDIES.md) for screenshot replacement instructions, contribution boundaries and release notes.
